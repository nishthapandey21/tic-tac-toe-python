# Tic Tac Toe | Python GUI Application

A desktop-based Tic Tac Toe game developed using Python and Tkinter, featuring an interactive 3×3 game board, two-player gameplay, and automated winner detection.

## Project Overview

This project demonstrates the use of Python programming concepts to develop an interactive desktop application. The graphical interface allows two players to take turns, while the game logic identifies winning combinations and manages gameplay.

## Key Features

* Interactive graphical user interface
* Two-player turn-based gameplay
* Automated winner detection
* Game restart functionality
* Voice-based winner announcements using text-to-speech

## Technology Stack

* **Language:** Python
* **GUI Framework:** Tkinter
* **Text-to-Speech:** pyttsx3
* **Development Environment:** PyCharm

## Installation and Setup

1. Install Python on your system.

2. Install the required dependency:

   `pip install pyttsx3`

3. Download the Python source file from this repository.

4. Open the file in PyCharm and run the application.
